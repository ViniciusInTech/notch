# Instalador para macOS

**[Baixar Notch.dmg](https://github.com/ViniciusInTech/notch/raw/refs/heads/main/installers/Notch.dmg)**

- macOS 14 ou superior; Apple Silicon.
- Abra o DMG e arraste Notch.app para Aplicativos.
- Use o [guia de configuração](../docs/SETUP.md) para login automático e permissões.
- Confira a integridade com o [SHA-256](SHA256SUMS.txt).

Este é um build de desenvolvimento com assinatura ad hoc, sem notarização.
O aplicativo é distribuído sob a [PolyForm Noncommercial 1.0.0](../LICENSE).
As condições e avisos também estão incluídos no instalador.
